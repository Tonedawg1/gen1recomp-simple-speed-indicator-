This is a simple Speed Indicator for Gen1Recomp. It just flashes a little text in the bottom left corner to let you know what speed your on. Full disclosure this was made with the help of AI.

Grab the latest zip from "Releases" on the right.

This mod should work with both gen 1 and gen 2 games.
